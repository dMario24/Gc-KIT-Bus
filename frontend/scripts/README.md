# 데이터베이스 시딩 (Seeding)

이 스크립트는 Supabase 데이터베이스에 데모 데이터를 채우기 위해 사용됩니다. 관리자, 기사, 일반 사용자 계정과 함께 버스 노선 및 버스 정보를 생성합니다.

## 실행 방법

이 스크립트를 실행하려면 Supabase 프로젝트의 `service_role` 키가 필요합니다. 이 키는 민감한 정보이므로 절대로 코드나 버전 관리에 포함해서는 안 됩니다.

1.  **Service Role 키 얻기**
    - Supabase 프로젝트 대시보드로 이동합니다.
    - 왼쪽 메뉴에서 **Settings** (톱니바퀴 아이콘) > **API**로 이동합니다.
    - "Project API keys" 섹션에서 `service_role`이라고 표시된 키를 복사합니다.

2.  **환경 변수 파일 생성**
    - `frontend` 디렉토리 최상단에 `.env` 파일을 생성합니다. (`.env.local` 파일과 같은 위치)
    - 파일에 아래 내용을 추가하고, 복사한 `service_role` 키를 붙여넣습니다.

    ```
    SUPABASE_SERVICE_KEY=여기에_복사한_service_role_키를_붙여넣으세요
    ```

3.  **의존성 설치**
    - `frontend` 디렉토리에서 터미널을 열고, 아직 설치하지 않았다면 다음 명령어를 실행하여 필요한 개발 의존성을 설치합니다.
    ```bash
    npm install
    ```

4.  **시딩 스크립트 실행**
    - 모든 설정이 완료되면 다음 명령어를 실행하여 데이터베이스에 데모 데이터를 추가합니다.
    ```bash
    npm run db:seed
    ```

스크립트가 성공적으로 실행되면 "✨ Seeding finished successfully!" 메시지가 표시됩니다. 이제 데모 계정으로 애플리케이션에 로그인하여 테스트할 수 있습니다.
